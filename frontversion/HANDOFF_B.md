## 差し替える入口

`src/services/B/live.js` は公開APIの必要メソッドと `authenticate` / `getStudyContext` をすべて列挙して503を返します。mockの関数を直接本番化するのではなく、このliveサービスからDB・AWSの実処理を呼んでください。引数は共通 `ctx`、返り値はJSON用オブジェクトです。`src/app.js` が認証、ルート割当、成功HTTPコード、エラーのJSON化を担当します。

`public/js/auth.js` の3関数をCognitoへ接続します。各API呼出時にaccess tokenを取得しBearerヘッダーへ設定します。ID tokenやユーザー指定のroleを認可に使用しないでください。トークンをURLやログに出さない設計です。

## 環境

| 変数 | 用途 |
|---|---|
| APP_MODE | mock / live。productionでmockは禁止 |
| NODE_ENV | productionではliveを既定にする |
| PORT / HOST | ローカルExpressの待受。初期3000 / 127.0.0.1 |
| API_BASE_URL | 初期 `/v1`。外部は `https://.../v1` のように末尾スラッシュなし |
| UPLOAD_ORIGINS | 署名アップロードに許可するHTTPS originをカンマ区切り。ワイルドカード不可 |

画面のruntime-config.jsは秘密情報を置く場所ではありません。S3の静的配信にする場合は同じ内容をデプロイ時に生成してください。外部APIのCORSはAuthorization、Content-Type、Idempotency-Keyを許可。API認証情報を署名アップロード先へ転送しません。

## ローカルモックの限界

メモリ保存・固定研修・固定役割です。Cognito、DB、S3、実マルウェア検査、再認証、利用枠の分散ロック、完全な復習間隔、所属期間・保持期限・実削除はありません。学習判定の一部を画面確認用に再現したもので、Bの完成実装として移植しないでください。
