# 情報Ⅱ 教員ラーニング：担当A修正版（B/C引継ぎ版）

前回の配布コードを基に、仕様書の05・11・12・13と共通仕様02〜08へ合わせた版です。ファイル名はv1.1ですが、提供ブック内の版表示はv1.2でした。今回の前提は「情報Ⅱ全分野」「05にない実装は未着手」「前回配布版を修正元」です。

**これは画面・接続契約案・ローカルモックです。AWS認証、永続化、AI検索、公式教材の取込・承認はまだ実装されていません。** 本番モードでモックへ自動的に切り替えることはありません。

## 既存プロジェクトへの配置

既存 `2026AWS-project` 直下へ、このZIPの `src/`、`public/`、`tests/` と説明ファイルを同じ階層で配置してください。前回の `src/index.js`、`public/index.html`、`public/js/*`、`public/css/style.css` は今回のファイルで置換します。ユーザー側で変更した版ではなく、前回配布版を基にしています。

- `.devcontainer/`、`cdk/`、`Dockerfile`、既存の `package.json`・lockfile は配布物に含めず、そのまま利用します。
- 旧 `src/demo/` は今回のコードから参照しません。必要な変更を退避した後、不要なら削除できます。
- 旧 `/api/*` は使いません。仕様書どおり `/v1/*` に統一しました。
- `package.example.json` は参考です。既存 `package.json` を無条件に上書きしないでください。Expressが既にあれば追加インストール不要です。
- テスト用のnpmスクリプトは `node --test tests/contracts.test.cjs` です。

既存の起動方法を使えます。

```bash
npm run dev
```

または直接起動します。

```bash
node src/index.js
```

初期値は `http://127.0.0.1:3000`。コンテナのポート公開で外部インターフェースへの待受が必要なら、開発環境内で `HOST=0.0.0.0` を設定します。

```bash
HOST=0.0.0.0 npm run dev
```

確認用のユーザーや成果物はメモリ保存で、再起動すると消えます。個人情報や実提出物を入れないでください。

`APP_MODE=live` にするとB/Cの `live.js` が選ばれます。用意された関数の中身を実装し、契約どおりのJSONを返せば画面側のURLを作り直す必要はありません。**05で未定義の詳細JSONは契約案であり、B/Cとの合意が必要です。** 「URLを変えるだけでAWS実装が完成する」という意味ではありません。

```bash
APP_MODE=live node src/index.js
```

`NODE_ENV=production` では既定がliveになり、mock指定を起動時に拒否します。

## 今回の主な変更

- 相関・因果に固定していた画面を解除。情報Ⅱ全5章、情報Ⅰ4章、指導資料区分を用意。
- 文部科学省の情報Ⅱ第3章は前半・後半の両PDFへ案内。導入・利用方法も別表示。
- 原典が公的に公開されていることと、アプリ内の承認・RAG取込を区別。
- API-01〜24を担当別に整理。API-12/13は内部関数でありHTTPに公開しない。
- `attempt_id`、`expected_version`、`Idempotency-Key`、AIの処理状態と結果状態を分離。
- 3件未満の知識スコアはnull。弱点候補は1回の誤答で断定しない。
- 能力評価0と未測定nullを区別。下書き評価では到達判定を変えない。
- 提出版を不変にし、改善は新しい提出版へ。評価下書き→人の確定→別評価者の申立て処理を分離。
- TXT/CSV/PY/IPYNBの提出添付を隔離・形式確認後に静的表示。コードは実行せず、IPYNBの出力は表示しない。
- 保存失敗時の入力保持、スマートフォン幅、HTML文字列の無害な表示を確認。

## 確認の順番

1. 受講教員として入り、章を切り替えて原典リンク・課題が連動することを確認。
2. 小テストを3回実行し、1〜2件ではスコアが未判定になることを確認。
3. 課題を入力し下書き保存、必要なら添付、提出。
4. 評価者へ切り替え、5軸と根拠を入力して下書き保存、次の画面で確定。
5. 受講教員の進捗・履歴を確認。申立て後は再評価者へ切り替える。
6. 教材作成者・承認者を切り替え、承認と公開が別であることを確認。
7. 管理者でAI緊急停止・削除依頼を確認。削除依頼は「受付」であり完了ではない。

モック小テストは全章とも接続確認用で、教材の理解を測る問題ではありません。AIは未取込の公的教材を根拠にしたふりをせず、`INSUFFICIENT` を返します。
