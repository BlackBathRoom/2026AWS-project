# C担当への引継ぎ

入口：src/services/C/live.js。API-06の教材相談はlesson_idを送信します。学習モード・援助可否・利用枠はBとサーバー側で検証してください。

- 文部科学省等の教材原典と、アプリで取込・承認・公開済みの版を分ける。
- Bedrock/Knowledge Basesへ承認済み教材のみを検索対象として接続。版・ページ・chunk_id付き出典を返す。
- モック回答はINSUFFICIENT固定。実回答に見せかけた文章を返していない。
- 自力評価中・AI停止時は作成時と取得時の両方で拒否。
- AIの最終採点は行わず、回答形式と根拠不足等の状態を維持。
- 管理画面のAI設定は停止・上限・答え許可のみ。モデル選択、検索基盤の変更、費用集計は未実装。
- PDF原本取込・隔離検査・公開・問題監修・教材撤回は本番処理に差し替える。

教材内相談UI：public/js/app.jsのviews.materials。既存の独立AI画面も維持しています。
