# 担当C：接続ToDo

対象は情報Ⅱ全5章、必要な情報Ⅰの補強、関連指導資料です。前回の「相関と因果」への固定は解除しました。文部科学省の公的教材への参照先は `public/data/catalog.json` にまとめています。これ以外の公的教材も同じ区分で追加できますが、網羅的に収集・利用許諾確認したものではありません。

## 差し替える入口

- `src/services/C/live.js`：教材・AI・管理API。共通ctxを受け取りJSONを返す。
- `getApprovedQuestion`：API-13。正解を含むためサーバー内部だけで使用。
- `getB().getStudyContext(ctx)`：API-12。AIの質問ごと・取得時にBの許可条件を確認。
- `public/data/catalog.json`：教材一覧APIが05にないため、公開の章構成と参照先だけを静的に置く。原本本文・採点用正解・私的データは置かない。

実教材の内容は `/v1/lessons/{id}` から取得します。公開/所属範囲を満たす版だけ返し、未公開は404としてください。今回のmockだけは接続確認文を返し `approved_version:null, fixture:true` と表示します。
